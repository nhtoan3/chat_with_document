## Mục tiêu

Tên tệp được chuẩn hóa (bỏ đường dẫn, NFC, ≤ 255 ký tự); khóa lưu trữ chỉ dùng UUID; tệp giả mạo / quá lớn bị từ chối.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/SEC-005/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/SEC-005`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/SEC-005/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/SEC-005/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/SEC-005/logs/` và `./test_reports/SEC-005/data/`.
6. **Tạo báo cáo** `./test_reports/SEC-005/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/SEC-005/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs SEC-005 test_reports/SEC-005/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Dữ liệu kiểm thử

- Không cần dữ liệu riêng.

## Các bước thực hiện

| # | Thao tác | Kết quả mong đợi | 📸 |
|---|---|---|---|
| 1 | Kiểm tra stack localhost và dọn dữ liệu | `Stack OK`; lệnh TRUNCATE thành công | 📸 |
| 2 | Tải tệp với tên `../../etc/passwd.pdf` | 202; tên lưu là `passwd.pdf` (không còn `../`) | 📸 |
| 3 | Tải tệp có tên 300 ký tự | 202; tên lưu ≤ 255 ký tự | 📸 |
| 4 | Tải tệp có tên Unicode dạng tổ hợp (NFD) `Báo_cáo.pdf` | 202; tên lưu ở dạng NFC | 📸 |
| 5 | Kiểm tra tên và khóa lưu trữ trong CSDL | Không tên nào chứa `/` hay `..`; `len` ≤ 255; `is_nfc = t`; `storage_key` dạng `documents/<uuid>.pdf` | 📸 |
| 6 | Tải `fake.pdf` và tệp 21 MB | Item `not_pdf` và `file_too_large` | 📸 |

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# SEC-005 — An toàn khi tải tệp (tên tệp, loại tệp, kích thước)
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs SEC-005 test_reports/SEC-005/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 2: Tải tệp với tên ../../etc/passwd.pdf"
curl -sS -w '\nHTTP %{http_code}\n' -X POST "$API_URL/api/v1/documents" -F "files=@$FIXTURES/sample/Hop_dong_khung_ABC_2026.pdf;filename=../../etc/passwd.pdf"

echo "### Bước 3: Tải tệp có tên 300 ký tự"
n=$(printf 'a%.0s' $(seq 1 296)).pdf; curl -sS -w '\nHTTP %{http_code}\n' -X POST "$API_URL/api/v1/documents" -F "files=@$FIXTURES/sample/De_xuat_hop_tac_Minh_Phat.pdf;filename=$n"

echo "### Bước 4: Tải tệp có tên Unicode dạng tổ hợp (NFD) Báo_cáo.pdf"
n=$(python3 -c "import unicodedata;print(unicodedata.normalize('NFD','Báo_cáo.pdf'))"); curl -sS -w '\nHTTP %{http_code}\n' -X POST "$API_URL/api/v1/documents" -F "files=@$FIXTURES/sample/Bien_ban_hop_doi_tac_15-09.pdf;filename=$n"

echo "### Bước 5: Kiểm tra tên và khóa lưu trữ trong CSDL"
psql_q "SELECT left(filename, 40) AS filename, length(filename) AS len, filename IS NFC NORMALIZED AS is_nfc, storage_key FROM documents;"

echo "### Bước 6: Tải fake.pdf và tệp 21 MB"
make_pdf big21mb "$DATA_DIR/qua_lon.pdf" >/dev/null; upload "$FIXTURES/fake.pdf" "$DATA_DIR/qua_lon.pdf"
```
