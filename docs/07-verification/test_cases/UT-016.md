## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/UT-016/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/UT-016`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/UT-016/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/UT-016/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/UT-016/logs/` và `./test_reports/UT-016/data/`.
6. **Tạo báo cáo** `./test_reports/UT-016/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/UT-016/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs UT-016 test_reports/UT-016/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# UT-016 — Prompt chứa đủ quy tắc bắt buộc và định dạng ngữ cảnh
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs UT-016 test_reports/UT-016/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Ghi nhận môi trường: commit, phiên bản Python và trạng thái stack localhost"
git rev-parse --short HEAD; backend/.venv/bin/python --version; check_stack || echo '(stack chưa chạy — không ảnh hưởng unit test)'

echo "### Bước 2: Chạy tests/unit/test_ask_usecase.py::test_prompt_contains_required_rules_and_context_format"
(cd backend && .venv/bin/pytest 'tests/unit/test_ask_usecase.py::test_prompt_contains_required_rules_and_context_format' -v)
```

## Tiêu chí đạt

Bước 2 kết thúc với exit code 0 và không có test nào failed / error.
