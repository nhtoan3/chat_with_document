## Mục tiêu

`encrypted.pdf`, `scanned.pdf`, `corrupted.pdf`, `301_pages.pdf` → `failed` với `encrypted_pdf`, `no_text_layer`, `corrupted`, `too_many_pages`.

3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/INT-007/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/INT-007/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/INT-007/logs/` và `./test_reports/INT-007/data/`.
6. **Tạo báo cáo** `./test_reports/INT-007/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.

## Điều kiện tiên quyết

- Đã tạo virtualenv backend (`make venv`).
- Docker Desktop đang chạy (Testcontainers tự dựng PostgreSQL + pgvector cho test tích hợp).
- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).

## Dữ liệu kiểm thử

- `fixtures/pdfs/{encrypted,scanned,corrupted}.pdf`
- `301_pages.pdf` sinh bằng `make_pdf pages301`

## Các bước thực hiện

| # | Thao tác | Kết quả mong đợi | 📸 |
|---|---|---|---|
| 1 | Chạy test tự động `tests/integration/test_documents.py::test_bad_pdfs_fail_with_code` (Testcontainers) | passed, exit code 0 | 📸 |
| 2 | Kiểm tra stack localhost và dọn dữ liệu | `Stack OK`; lệnh TRUNCATE thành công | 📸 |
| 3 | Sinh PDF 301 trang | Tệp hợp lệ 301 trang trong `data/` | 📸 |
| 4 | Tải lên 4 tệp lỗi | HTTP 202; 4 item `queued` (hoặc `corrupted.pdf` bị `not_pdf` nếu không có header `%PDF-` — ghi nhận) | 📸 |
| 5 | Chờ xử lý và xem mã lỗi | encrypted → `encrypted_pdf`; scanned → `no_text_layer`; corrupted → `corrupted`; 301_pages → `too_many_pages`; tất cả `failed` | 📸 |

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# INT-007 — PDF lỗi được đánh dấu failed với mã tương ứng
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs INT-007 test_reports/INT-007/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Chạy test tự động tests/integration/test_documents.py::test_bad_pdfs_fail_with_code (Testcontainers)"
(cd backend && .venv/bin/pytest 'tests/integration/test_documents.py::test_bad_pdfs_fail_with_code' -v)

echo "### Bước 2: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 3: Sinh PDF 301 trang"
make_pdf pages301 "$DATA_DIR/301_pages.pdf"

echo "### Bước 4: Tải lên 4 tệp lỗi"
upload "$FIXTURES/encrypted.pdf" "$FIXTURES/scanned.pdf" "$FIXTURES/corrupted.pdf" "$DATA_DIR/301_pages.pdf"

echo "### Bước 5: Chờ xử lý và xem mã lỗi"
wait_idle 300; psql_q "SELECT filename, status, error_code FROM documents ORDER BY filename;"
```

## Tiêu chí đạt

Mỗi tệp có đúng `status = failed` và `error_code` như mong đợi.

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.
