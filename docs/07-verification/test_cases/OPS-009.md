## Mục tiêu

Truy vấn số liệu theo tuần trong T-024 chạy được và trả số câu hỏi, p90 độ trễ.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/OPS-009/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/OPS-009`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/OPS-009/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/OPS-009/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/OPS-009/logs/` và `./test_reports/OPS-009/data/`.
6. **Tạo báo cáo** `./test_reports/OPS-009/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/OPS-009/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs OPS-009 test_reports/OPS-009/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).

## Dữ liệu kiểm thử

- Không cần dữ liệu riêng.

## Các bước thực hiện

| # | Thao tác | Kết quả mong đợi | 📸 |
|---|---|---|---|
| 1 | Kiểm tra stack localhost và dọn dữ liệu | `Stack OK`; lệnh TRUNCATE thành công | 📸 |
| 2 | Tạo vài dòng `qa_log` (không cần khóa API) | 409 / 503 / 200 tùy dữ liệu | 📸 |
| 3 | Chạy truy vấn số liệu của T-024 | Một dòng theo tuần với `count` và `percentile_cont` | 📸 |

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# OPS-009 — Truy vấn số liệu pilot chạy được
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs OPS-009 test_reports/OPS-009/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 2: Tạo vài dòng qa_log (không cần khóa API)"
seed_samples; wait_idle 300; for q in 'Câu 1' 'Câu 2' 'Câu 3'; do ask "$q" >/dev/null; done; psql_q "SELECT count(*) FROM qa_log;"

echo "### Bước 3: Chạy truy vấn số liệu của T-024"
psql_q "SELECT date_trunc('week', created_at) AS tuan, count(*) AS so_cau_hoi, percentile_cont(0.9) WITHIN GROUP (ORDER BY latency_ms) AS p90_ms FROM qa_log GROUP BY 1 ORDER BY 1;"
```

## Tiêu chí đạt

Truy vấn chạy không lỗi và trả số liệu.

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.
