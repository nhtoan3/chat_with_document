## Mục tiêu

Endpoint `/healthz` và trang web localhost phản hồi.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/INT-021/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/INT-021`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/INT-021/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/INT-021/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/INT-021/logs/` và `./test_reports/INT-021/data/`.
6. **Tạo báo cáo** `./test_reports/INT-021/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/INT-021/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs INT-021 test_reports/INT-021/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).

## Dữ liệu kiểm thử

- Không cần dữ liệu riêng.

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# INT-021 — /healthz trả 200
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs INT-021 test_reports/INT-021/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Gọi /healthz"
curl -sS -i "$API_URL/healthz"

echo "### Bước 2: Gọi trang web gốc"
curl -sS -i "$WEB_URL/" | head -30
```
