## Mục tiêu

Nút Gửi bị khóa khi câu hỏi rỗng hoặc > 2000 ký tự; bộ đếm đúng; Shift+Enter xuống dòng.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/E2E-006/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/E2E-006`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/E2E-006/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/E2E-006/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/E2E-006/logs/` và `./test_reports/E2E-006/data/`.
6. **Tạo báo cáo** `./test_reports/E2E-006/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần UI: viết script Playwright `./test_reports/E2E-006/E2E-006.mjs` dùng `startEvidence('E2E-006')` từ `frontend/e2e/evidence.mjs` (`caption()` đầu mỗi bước, `shot()` tại mỗi 📸, `finish()` ở cuối) và chạy `node test_reports/E2E-006/E2E-006.mjs` từ gốc repo. Xem ví dụ ở README §4.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).
- Đã chạy `npm ci` trong `frontend/` (có Playwright 1.64.1).
- Có ≥ 1 tài liệu Sẵn sàng (`reset_data && seed_samples && wait_idle`).
- Giả lập `/api/v1/ask` bằng `page.route` để đếm request (không gọi Claude).

## Dữ liệu kiểm thử

- Không cần dữ liệu riêng.

## Các bước thực hiện

| # | Thao tác | Kết quả mong đợi | 📸 |
|---|---|---|---|
| 1 | Mở `/ask`, nhập 5 dấu cách | Nút "Gửi câu hỏi" bị vô hiệu; nhấn Enter không tạo request | 📸 |
| 2 | Dán 2001 ký tự | Bộ đếm "2001/2000"; thông báo "Câu hỏi dài quá 1 ký tự."; nút Gửi bị vô hiệu | 📸 |
| 3 | Xóa 1 ký tự (còn 2000) | Bộ đếm "2000/2000"; nút Gửi dùng được | 📸 |
| 4 | Xóa hết, gõ "dòng 1", nhấn Shift+Enter, gõ "dòng 2" | Ô nhập có 2 dòng; không có request `/api/v1/ask` | 📸 |
| 5 | Nhấn Enter | Đúng 1 request `/api/v1/ask` với `question` chứa xuống dòng | 📸 |
