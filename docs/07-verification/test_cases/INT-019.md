## Mục tiêu

Khi dịch vụ embedding không khả dụng, `/ask` trả 503 `ai_unavailable` và ghi `qa_log.status = 'error'`.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/INT-019/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/INT-019`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/INT-019/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/INT-019/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/INT-019/logs/` và `./test_reports/INT-019/data/`.
6. **Tạo báo cáo** `./test_reports/INT-019/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/INT-019/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs INT-019 test_reports/INT-019/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).
- Test dừng container `tei` trong khoảng 1 phút.

## Dữ liệu kiểm thử

- Không cần dữ liệu riêng.

## Các bước thực hiện

| # | Thao tác | Kết quả mong đợi | 📸 |
|---|---|---|---|
| 1 | Kiểm tra stack localhost và dọn dữ liệu | `Stack OK`; lệnh TRUNCATE thành công | 📸 |
| 2 | Nạp PDF mẫu | `ready: 3` | 📸 |
| 3 | Dừng TEI | Container `tei` stopped | 📸 |
| 4 | Hỏi một câu | HTTP 503, `code: ai_unavailable` | 📸 |
| 5 | Kiểm tra `qa_log` | Dòng mới nhất `status = error` | 📸 |
| 6 | Bật lại TEI | Container `tei` chạy | 📸 |

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# INT-019 — TEI lỗi khi hỏi → 503 ai_unavailable
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs INT-019 test_reports/INT-019/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 2: Nạp PDF mẫu"
seed_samples; wait_idle 300

echo "### Bước 3: Dừng TEI"
"${COMPOSE[@]}" stop tei

echo "### Bước 4: Hỏi một câu"
ask 'Minh Phát đề xuất mức chiết khấu bao nhiêu?'

echo "### Bước 5: Kiểm tra qa_log"
psql_q "SELECT id, status, latency_ms FROM qa_log ORDER BY id DESC LIMIT 1;"

echo "### Bước 6: Bật lại TEI"
"${COMPOSE[@]}" start tei; sleep 5; "${COMPOSE[@]}" ps tei
```

## Tiêu chí đạt

Bước 4 trả 503 `ai_unavailable`, bước 5 có dòng `status = error`.

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.

- Đảm bảo `tei` đã chạy lại
