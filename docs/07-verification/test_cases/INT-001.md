## Mục tiêu

`POST /api/v1/documents` nhận 3 PDF mẫu, worker xử lý tới `ready` và ghi chunk.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/INT-001/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/INT-001`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/INT-001/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/INT-001/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/INT-001/logs/` và `./test_reports/INT-001/data/`.
6. **Tạo báo cáo** `./test_reports/INT-001/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/INT-001/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs INT-001 test_reports/INT-001/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Đã tạo virtualenv backend (`make venv`).
- Docker Desktop đang chạy (Testcontainers tự dựng PostgreSQL + pgvector cho test tích hợp).
- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).

## Dữ liệu kiểm thử

|---|---|---|---|
| 1 | Chạy test tự động `tests/integration/test_documents.py::test_upload_three_valid_pdfs_then_ingest` (Testcontainers) | passed, exit code 0 | 📸 |

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# INT-001 — Tải lên 3 PDF hợp lệ rồi xử lý tới Sẵn sàng
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs INT-001 test_reports/INT-001/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Chạy test tự động tests/integration/test_documents.py::test_upload_three_valid_pdfs_then_ingest (Testcontainers)"
(cd backend && .venv/bin/pytest 'tests/integration/test_documents.py::test_upload_three_valid_pdfs_then_ingest' -v)

echo "### Bước 2: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 3: Tải lên 3 PDF mẫu"
seed_samples

echo "### Bước 4: Chờ worker xử lý xong"
wait_idle 300

echo "### Bước 5: Kiểm tra trạng thái, số trang và số chunk trong CSDL"
psql_q "SELECT d.filename, d.status, d.pages, count(c.id) AS chunks FROM documents d LEFT JOIN chunks c ON c.document_id = d.id GROUP BY 1,2,3 ORDER BY 1;"
```
