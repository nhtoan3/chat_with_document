## Mục tiêu

Với Claude thật, câu hỏi có đáp án nhận câu trả lời tiếng Việt đúng ý; câu ngoài tài liệu nhận "không tìm thấy".

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/INT-022/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/INT-022`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/INT-022/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/INT-022/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/INT-022/logs/` và `./test_reports/INT-022/data/`.
6. **Tạo báo cáo** `./test_reports/INT-022/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/INT-022/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs INT-022 test_reports/INT-022/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).
- Có `ANTHROPIC_API_KEY` trong `.env` ở gốc repo và đã khởi động lại api (`docker compose up -d api`). Không có khóa → kết luận **⛔ Bị chặn**.

## Dữ liệu kiểm thử

- 3 PDF mẫu; câu hỏi lấy từ `backend/tests/eval/golden.yaml` (G-001, G-002, G-003, G-051).

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# INT-022 — Gọi Claude thật với tài liệu mẫu (live)
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs INT-022 test_reports/INT-022/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 2: Nạp PDF mẫu"
seed_samples; wait_idle 300

echo "### Bước 3: G-001: điều khoản tạm ứng ABC"
ask 'Điều khoản tạm ứng trong hợp đồng khung với ABC là gì?'

echo "### Bước 4: G-002: mức phạt chậm thanh toán"
ask 'Mức phạt khi chậm thanh toán là bao nhiêu?'

echo "### Bước 5: G-003: chiết khấu Minh Phát"
ask 'Minh Phát đề xuất mức chiết khấu bao nhiêu?'

echo "### Bước 6: G-051: câu ngoài tài liệu"
ask 'Thủ đô của Pháp là gì?'
```

## Tiêu chí đạt

3 câu positive đúng ý và bằng tiếng Việt; câu negative trả "không tìm thấy".

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.
