## Mục tiêu

Khi số tài liệu hiện có + số tệp mới > 50 → 409 `collection_full`; đúng 50 thì vẫn nhận.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/INT-006/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/INT-006`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/INT-006/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/INT-006/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/INT-006/logs/` và `./test_reports/INT-006/data/`.
6. **Tạo báo cáo** `./test_reports/INT-006/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/INT-006/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs INT-006 test_reports/INT-006/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Đã tạo virtualenv backend (`make venv`).
- Docker Desktop đang chạy (Testcontainers tự dựng PostgreSQL + pgvector cho test tích hợp).
- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).

## Dữ liệu kiểm thử

- 49 bản ghi giả chèn trực tiếp vào bảng `documents` (trạng thái `failed`).

## Các bước thực hiện

| # | Thao tác | Kết quả mong đợi | 📸 |
|---|---|---|---|
| 1 | Chạy test tự động `tests/integration/test_documents.py::test_collection_full` (Testcontainers) | passed, exit code 0 | 📸 |
| 2 | Kiểm tra stack localhost và dọn dữ liệu | `Stack OK`; lệnh TRUNCATE thành công | 📸 |
| 3 | Chèn 49 tài liệu giả | `INSERT 0 49` | 📸 |
| 4 | Tải lên 2 PDF (49 + 2 > 50) | HTTP 409, `code: "collection_full"` | 📸 |
| 5 | Tải lên 1 PDF (49 + 1 = 50) | HTTP 202, `status: queued` | 📸 |
| 6 | Đếm tài liệu | `total: 50` | 📸 |

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# INT-006 — Bộ tài liệu đạt giới hạn 50
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs INT-006 test_reports/INT-006/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Chạy test tự động tests/integration/test_documents.py::test_collection_full (Testcontainers)"
(cd backend && .venv/bin/pytest 'tests/integration/test_documents.py::test_collection_full' -v)

echo "### Bước 2: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 3: Chèn 49 tài liệu giả"
psql_q "INSERT INTO documents (filename, size_bytes, status, error_code, storage_key) SELECT 'gia-lap-' || g || '.pdf', 1, 'failed', 'corrupted', 'placeholder/' || g FROM generate_series(1, 49) g;"

echo "### Bước 4: Tải lên 2 PDF (49 + 2 > 50)"
upload "$FIXTURES/sample/Hop_dong_khung_ABC_2026.pdf" "$FIXTURES/sample/De_xuat_hop_tac_Minh_Phat.pdf"

echo "### Bước 5: Tải lên 1 PDF (49 + 1 = 50)"
upload "$FIXTURES/sample/Hop_dong_khung_ABC_2026.pdf"

echo "### Bước 6: Đếm tài liệu"
counts
```

## Tiêu chí đạt

Bước 4 trả 409 `collection_full`, bước 5 trả 202, tổng 50 tài liệu.

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.
