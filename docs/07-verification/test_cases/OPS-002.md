## Mục tiêu

Lệnh `make seed` tải 3 PDF mẫu lên stack và chúng chuyển Sẵn sàng.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/OPS-002/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/OPS-002`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/OPS-002/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/OPS-002/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/OPS-002/logs/` và `./test_reports/OPS-002/data/`.
6. **Tạo báo cáo** `./test_reports/OPS-002/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/OPS-002/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs OPS-002 test_reports/OPS-002/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Đã tạo virtualenv backend (`make venv`).
- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).

## Dữ liệu kiểm thử

- Không cần dữ liệu riêng.

## Các bước thực hiện

| # | Thao tác | Kết quả mong đợi | 📸 |
|---|---|---|---|
| 1 | Kiểm tra stack localhost và dọn dữ liệu | `Stack OK`; lệnh TRUNCATE thành công | 📸 |
| 2 | Chạy `make seed` | JSON 3 item `queued` | 📸 |
| 3 | Chờ xử lý | `{ready:3, processing:0, failed:0, total:3}` | 📸 |

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# OPS-002 — make seed nạp 3 PDF mẫu tới Sẵn sàng
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs OPS-002 test_reports/OPS-002/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 2: Chạy make seed"
make seed

echo "### Bước 3: Chờ xử lý"
wait_idle 300
```

## Tiêu chí đạt

3 tài liệu Sẵn sàng.

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.
