## Mục tiêu

Khi TEI không khả dụng, job được thử lại theo backoff 10 / 40 / 160 s rồi tài liệu `failed` với `transient_exhausted`; tài liệu khác không bị ảnh hưởng.

## Điều kiện tiên quyết

- Đã tạo virtualenv backend (`make venv`).
- Docker Desktop đang chạy (Testcontainers tự dựng PostgreSQL + pgvector cho test tích hợp).
- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).
- Test dừng container `tei` khoảng 4–5 phút.

## Dữ liệu kiểm thử

- Không cần dữ liệu riêng.

## Các bước thực hiện

| # | Thao tác | Kết quả mong đợi | 📸 |
|---|---|---|---|
| 1 | Chạy test tự động `tests/integration/test_documents.py::test_transient_errors_retry_then_give_up` (Testcontainers) | passed, exit code 0 | 📸 |
| 2 | Kiểm tra stack localhost và dọn dữ liệu | `Stack OK`; lệnh TRUNCATE thành công | 📸 |
| 3 | Dừng TEI | Container `tei` stopped | 📸 |
| 4 | Tải lên 1 PDF mẫu | HTTP 202, `queued` | 📸 |
| 5 | Theo dõi job mỗi 20 giây trong tối đa 6 phút | `attempt` tăng 1 → 2 → 3, `next_run_at` giãn theo backoff; cuối cùng `state` kết thúc và tài liệu `failed` / `transient_exhausted` | 📸 |
| 6 | Bật lại TEI | Container `tei` healthy | 📸 |

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# INT-008 — Lỗi tạm thời: thử lại 3 lần rồi transient_exhausted
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs INT-008 test_reports/INT-008/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Chạy test tự động tests/integration/test_documents.py::test_transient_errors_retry_then_give_up (Testcontainers)"
(cd backend && .venv/bin/pytest 'tests/integration/test_documents.py::test_transient_errors_retry_then_give_up' -v)

echo "### Bước 2: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 3: Dừng TEI"
"${COMPOSE[@]}" stop tei

echo "### Bước 4: Tải lên 1 PDF mẫu"
upload "$FIXTURES/sample/Hop_dong_khung_ABC_2026.pdf"

echo "### Bước 5: Theo dõi job mỗi 20 giây trong tối đa 6 phút"
for i in $(seq 1 18); do psql_q "SELECT now()::time(0) AS luc, j.state, j.attempt, j.next_run_at::time(0), d.status, d.error_code FROM ingestion_jobs j JOIN documents d ON d.id = j.document_id;"; s=$(curl -sS "$API_URL/api/v1/documents" | jq -r '.items[0].status'); [ "$s" = failed ] && break; sleep 20; done

echo "### Bước 6: Bật lại TEI"
"${COMPOSE[@]}" start tei; sleep 5; "${COMPOSE[@]}" ps tei
```

## Tiêu chí đạt

Tài liệu kết thúc ở `failed` với `error_code = transient_exhausted` sau 3 lần thử, khoảng cách giữa các lần thử tăng dần.

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.
