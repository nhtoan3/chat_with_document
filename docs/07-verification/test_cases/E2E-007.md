## Mục tiêu

Khi `/ask` trả 503, giao diện hiện thông điệp thân thiện và nút Hỏi lại; Hỏi lại thành công thì hiện câu trả lời.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/E2E-007/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/E2E-007`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/E2E-007/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/E2E-007/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/E2E-007/logs/` và `./test_reports/E2E-007/data/`.
6. **Tạo báo cáo** `./test_reports/E2E-007/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần UI: viết script Playwright `./test_reports/E2E-007/E2E-007.mjs` dùng `startEvidence('E2E-007')` từ `frontend/e2e/evidence.mjs` (`caption()` đầu mỗi bước, `shot()` tại mỗi 📸, `finish()` ở cuối) và chạy `node test_reports/E2E-007/E2E-007.mjs` từ gốc repo. Xem ví dụ ở README §4.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).
- Đã chạy `npm ci` trong `frontend/` (có Playwright 1.64.1).
- Có ≥ 1 tài liệu Sẵn sàng.
- Giả lập `/api/v1/ask` bằng `page.route`: lần 1 trả 503 `application/problem+json` `{"type":"about:blank","title":"AI service unavailable","status":503,"code":"ai_unavailable"}`; lần 2 trả 200 `{"answer":"Câu trả lời sau khi hỏi lại.","latency_ms":1200}`.
