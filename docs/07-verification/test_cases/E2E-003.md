## Mục tiêu

Chọn quá 10 tệp thì không gửi request; tệp > 20 MB bị báo lỗi tại tệp đó, tệp hợp lệ vẫn được gửi.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/E2E-003/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/E2E-003`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/E2E-003/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/E2E-003/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/E2E-003/logs/` và `./test_reports/E2E-003/data/`.
6. **Tạo báo cáo** `./test_reports/E2E-003/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần UI: viết script Playwright `./test_reports/E2E-003/E2E-003.mjs` dùng `startEvidence('E2E-003')` từ `frontend/e2e/evidence.mjs` (`caption()` đầu mỗi bước, `shot()` tại mỗi 📸, `finish()` ở cuối) và chạy `node test_reports/E2E-003/E2E-003.mjs` từ gốc repo. Xem ví dụ ở README §4.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).
- Đã chạy `npm ci` trong `frontend/` (có Playwright 1.64.1).
- `reset_data`; sinh dữ liệu bằng `TEST_DIR=test_reports/E2E-003 bash -c 'source frontend/e2e/lib.sh; for i in $(seq -w 1 11); do cp backend/tests/fixtures/pdfs/sample/Hop_dong_khung_ABC_2026.pdf $DATA_DIR/tep_$i.pdf; done; make_pdf big21mb $DATA_DIR/qua_lon.pdf'`.

## Dữ liệu kiểm thử

- 11 PDF trong `test_reports/E2E-003/data/`
- `qua_lon.pdf` 21 MB
