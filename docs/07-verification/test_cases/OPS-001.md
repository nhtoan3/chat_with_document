## Mục tiêu

Toàn bộ dịch vụ local chạy và phản hồi: postgres, s3, tei, api, worker ×2, web.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/OPS-001/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/OPS-001`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/OPS-001/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/OPS-001/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/OPS-001/logs/` và `./test_reports/OPS-001/data/`.
6. **Tạo báo cáo** `./test_reports/OPS-001/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/OPS-001/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs OPS-001 test_reports/OPS-001/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Docker Desktop ≥ 8 GB RAM.
- Lần đầu TEI tải model ~2,3 GB.

## Dữ liệu kiểm thử

- Không cần dữ liệu riêng.

## Các bước thực hiện

| # | Thao tác | Kết quả mong đợi | 📸 |
|---|---|---|---|
| 1 | Khởi động stack | Lệnh kết thúc, in URL web và API | 📸 |
| 2 | Chờ TEI healthy (tối đa 15 phút) | `tei` healthy | 📸 |
| 3 | Liệt kê dịch vụ | postgres (healthy), s3, tei (healthy), api, 2 worker, web đều `running`; migrate `exited (0)` | 📸 |
| 4 | Gọi từng endpoint | API `/healthz` 200; web 200; TEI `/health` 200; S3Mock 200 | 📸 |

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# OPS-001 — make dev dựng đủ stack healthy
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs OPS-001 test_reports/OPS-001/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Khởi động stack"
make dev

echo "### Bước 2: Chờ TEI healthy (tối đa 15 phút)"
for i in $(seq 1 90); do s=$(docker inspect -f '{{.State.Health.Status}}' $("${COMPOSE[@]}" ps -q tei)); echo "tei: $s"; [ "$s" = healthy ] && break; sleep 10; done

echo "### Bước 3: Liệt kê dịch vụ"
"${COMPOSE[@]}" ps -a

echo "### Bước 4: Gọi từng endpoint"
check_stack; curl -sS -o /dev/null -w 'TEI %{http_code}\n' http://localhost:8080/health; curl -sS -o /dev/null -w 'S3Mock %{http_code}\n' http://localhost:9090/
```

## Tiêu chí đạt

Mọi dịch vụ chạy và mọi endpoint trả 200.

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.
