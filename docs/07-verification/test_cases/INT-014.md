## Mục tiêu

`POST /api/v1/ask` trả 200 `{answer, latency_ms}`; `qa_log` chỉ có cột số liệu.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/INT-014/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/INT-014`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/INT-014/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/INT-014/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/INT-014/logs/` và `./test_reports/INT-014/data/`.
6. **Tạo báo cáo** `./test_reports/INT-014/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/INT-014/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs INT-014 test_reports/INT-014/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Đã tạo virtualenv backend (`make venv`).
- Docker Desktop đang chạy (Testcontainers tự dựng PostgreSQL + pgvector cho test tích hợp).
- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).
- Có `ANTHROPIC_API_KEY` trong `.env` ở gốc repo và đã khởi động lại api (`docker compose up -d api`). Không có khóa → kết luận **⛔ Bị chặn**. (Chỉ áp dụng cho bước 4; bước 1 dùng FakeLLM, luôn chạy được.)

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# INT-014 — Hỏi đáp thành công và qa_log không chứa nội dung
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs INT-014 test_reports/INT-014/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Chạy test tự động tests/integration/test_ask.py::test_ask_returns_answer_and_logs_without_content (Testcontainers)"
(cd backend && .venv/bin/pytest 'tests/integration/test_ask.py::test_ask_returns_answer_and_logs_without_content' -v)

echo "### Bước 2: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 3: Nạp 3 PDF mẫu"
seed_samples; wait_idle 300

echo "### Bước 4: Hỏi \"Điều khoản tạm ứng trong hợp đồng khung với ABC là gì?\""
ask 'Điều khoản tạm ứng trong hợp đồng khung với ABC là gì?'

echo "### Bước 5: Kiểm tra cột và dòng mới nhất của qa_log"
psql_q "SELECT column_name FROM information_schema.columns WHERE table_name = 'qa_log' ORDER BY ordinal_position;"; psql_q "SELECT * FROM qa_log ORDER BY id DESC LIMIT 1;"
```

## Tiêu chí đạt

Bước 1 passed; bước 4 trả 200 với câu trả lời đúng ý; `qa_log` không có cột chứa văn bản.
