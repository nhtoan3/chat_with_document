## Mục tiêu

Body không phải JSON, thiếu `question` hoặc sai kiểu đều trả 422 `question_invalid` dạng `application/problem+json`.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/INT-016/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/INT-016`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/INT-016/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/INT-016/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/INT-016/logs/` và `./test_reports/INT-016/data/`.
6. **Tạo báo cáo** `./test_reports/INT-016/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.

8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).

## Dữ liệu kiểm thử

- Không cần dữ liệu riêng.

## Các bước thực hiện

| # | Thao tác | Kết quả mong đợi | 📸 |
|---|---|---|---|
| 1 | Kiểm tra stack localhost và dọn dữ liệu | `Stack OK`; lệnh TRUNCATE thành công | 📸 |
| 2 | Body không phải JSON | HTTP 422, `content-type: application/problem+json`, `code: question_invalid` | 📸 |
| 3 | Body `{}` | HTTP 422, `code: question_invalid` | 📸 |
| 4 | Body `{"question": 123}` | HTTP 422, `code: question_invalid` | 📸 |

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# INT-016 — Body không hợp lệ → 422 question_invalid (problem+json)
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs INT-016 test_reports/INT-016/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 2: Body không phải JSON"
curl -sS -i -X POST "$API_URL/api/v1/ask" -H 'content-type: application/json' -d 'khong-phai-json'

echo "### Bước 3: Body {}"
curl -sS -w '\nHTTP %{http_code}\n' -X POST "$API_URL/api/v1/ask" -H 'content-type: application/json' -d '{}'

echo "### Bước 4: Body {\"question\": 123}"
curl -sS -w '\nHTTP %{http_code}\n' -X POST "$API_URL/api/v1/ask" -H 'content-type: application/json' -d '{"question": 123}'
```

## Tiêu chí đạt

Cả 3 request trả 422 problem+json với `code: question_invalid`.

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.
