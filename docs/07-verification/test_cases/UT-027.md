## Mục tiêu

Mỗi khóa trong `backend/app/platform/errors.py::ERRORS` và mỗi `error_code` của ingestion đều có thông điệp trong `frontend/src/shared/i18n/vi.json` (`errors.*`).

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/UT-027/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/UT-027`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/UT-027/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/UT-027/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/UT-027/logs/` và `./test_reports/UT-027/data/`.
6. **Tạo báo cáo** `./test_reports/UT-027/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/UT-027/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs UT-027 test_reports/UT-027/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Các bước thực hiện

| # | Thao tác | Kết quả mong đợi | 📸 |
|---|---|---|---|
| 1 | Liệt kê mã lỗi phía backend (ERRORS + mã ingestion) | Danh sách 11 mã của ERRORS và 5 mã ingestion | 📸 |

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# UT-027 — Mọi mã lỗi đều có thông điệp tiếng Việt trong vi.json
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs UT-027 test_reports/UT-027/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Liệt kê mã lỗi phía backend (ERRORS + mã ingestion)"
(cd backend && .venv/bin/python -c "from app.platform.errors import ERRORS; print(sorted(ERRORS))"); echo 'ingestion: encrypted_pdf no_text_layer too_many_pages corrupted transient_exhausted'

echo "### Bước 2: So sánh với errors trong vi.json"
(cd backend && .venv/bin/python - <<'PY'
import json
from app.platform.errors import ERRORS
codes = set(ERRORS) | {'encrypted_pdf','no_text_layer','too_many_pages','corrupted','transient_exhausted'}
vi = json.load(open('../frontend/src/shared/i18n/vi.json', encoding='utf-8'))['errors']
print('THIẾU:', sorted(codes - set(vi)))
print('Thừa (chỉ phía frontend, chấp nhận được):', sorted(set(vi) - codes))
PY
)
```

## Tiêu chí đạt

Bước 2 in `THIẾU: []`.

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.
