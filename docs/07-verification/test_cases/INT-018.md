## Mục tiêu

Khi gọi Claude thất bại, API trả 503 `ai_unavailable` và ghi `qa_log.status = 'error'`.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/INT-018/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/INT-018`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/INT-018/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/INT-018/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/INT-018/logs/` và `./test_reports/INT-018/data/`.
6. **Tạo báo cáo** `./test_reports/INT-018/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/INT-018/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs INT-018 test_reports/INT-018/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Đã tạo virtualenv backend (`make venv`).
- Docker Desktop đang chạy (Testcontainers tự dựng PostgreSQL + pgvector cho test tích hợp).
- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).
- Bước trên stack dùng khóa API không hợp lệ (script tự khởi động lại api với `ANTHROPIC_API_KEY=sk-ant-invalid`).

## Dữ liệu kiểm thử

- Không cần dữ liệu riêng.

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# INT-018 — LLM lỗi → 503 ai_unavailable và qa_log status error
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs INT-018 test_reports/INT-018/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Chạy test tự động tests/integration/test_ask.py::test_llm_failure_is_503_and_logged (Testcontainers)"
(cd backend && .venv/bin/pytest 'tests/integration/test_ask.py::test_llm_failure_is_503_and_logged' -v)

echo "### Bước 2: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 3: Nạp PDF mẫu"
seed_samples; wait_idle 300

echo "### Bước 4: Khởi động lại api với khóa API không hợp lệ"
ANTHROPIC_API_KEY=sk-ant-invalid "${COMPOSE[@]}" up -d --force-recreate api; for i in $(seq 1 30); do curl -fsS "$API_URL/healthz" >/dev/null && break; sleep 2; done; echo healthz OK

echo "### Bước 5: Hỏi một câu"
ask 'Mức phạt khi chậm thanh toán là bao nhiêu?'

echo "### Bước 6: Kiểm tra qa_log"
psql_q "SELECT id, status, latency_ms, chunk_count FROM qa_log ORDER BY id DESC LIMIT 1;"

echo "### Bước 7: Khôi phục api với cấu hình gốc"
"${COMPOSE[@]}" up -d --force-recreate api; sleep 5; check_stack
```

## Tiêu chí đạt

Bước 6 trả 503 `ai_unavailable` và bước 7 có dòng `status = error`.

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.

## Dọn dẹp sau test

- Khôi phục api (bước 8)
- `reset_data`
