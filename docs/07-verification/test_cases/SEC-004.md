## Mục tiêu

Xác nhận cả ở mức unit (`markdown.ts`) và trên trình duyệt rằng HTML độc hại trong câu trả lời không được thực thi.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/SEC-004/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/SEC-004`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/SEC-004/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/SEC-004/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/SEC-004/logs/` và `./test_reports/SEC-004/data/`.
6. **Tạo báo cáo** `./test_reports/SEC-004/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/SEC-004/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs SEC-004 test_reports/SEC-004/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Phần UI: viết script Playwright `./test_reports/SEC-004/SEC-004.mjs` dùng `startEvidence('SEC-004')` từ `frontend/e2e/evidence.mjs` (`caption()` đầu mỗi bước, `shot()` tại mỗi 📸, `finish()` ở cuối) và chạy `node test_reports/SEC-004/SEC-004.mjs` từ gốc repo. Xem ví dụ ở README §4.
9. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Đã chạy `npm ci` trong `frontend/` (có Playwright 1.64.1).
- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).
- Có ≥ 1 tài liệu Sẵn sàng.

## Dữ liệu kiểm thử

- Không cần dữ liệu riêng.

## Script gợi ý (`steps.sh`)

Chỉ gồm các bước CLI; các bước UI làm bằng script Playwright.

```bash
#!/usr/bin/env bash
# SEC-004 — Chống XSS trong câu trả lời
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs SEC-004 test_reports/SEC-004/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: (CLI) Chạy npx vitest run src/features/ask/markdown.test.ts"
(cd frontend && npx vitest run src/features/ask/markdown.test.ts --reporter=verbose)
```
