## Mục tiêu

Job ở trạng thái `running` quá `WORKER_STALE_JOB_MINUTES` (10 phút) được đưa lại hàng đợi. Kịch bản thực tế trên stack (kill worker khi đang xử lý) nằm ở OPS-007.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/INT-010/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/INT-010`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/INT-010/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/INT-010/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/INT-010/logs/` và `./test_reports/INT-010/data/`.
6. **Tạo báo cáo** `./test_reports/INT-010/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/INT-010/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs INT-010 test_reports/INT-010/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# INT-010 — Thu hồi job treo (running quá hạn)
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs INT-010 test_reports/INT-010/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Ghi nhận môi trường localhost"
git rev-parse --short HEAD; check_stack || echo '(stack chưa chạy — không ảnh hưởng test này)'

echo "### Bước 2: Chạy test tự động tests/integration/test_documents.py::test_stale_running_job_is_reclaimed (Testcontainers)"
(cd backend && .venv/bin/pytest 'tests/integration/test_documents.py::test_stale_running_job_is_reclaimed' -v)
```
