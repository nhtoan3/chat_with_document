## Mục tiêu

Khi không có khóa API, `/ask` trả 503 `ai_unavailable`; tải lên và danh sách tài liệu vẫn hoạt động.

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/OPS-008/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/OPS-008`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/OPS-008/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/OPS-008/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/OPS-008/logs/` và `./test_reports/OPS-008/data/`.
6. **Tạo báo cáo** `./test_reports/OPS-008/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.

## Điều kiện tiên quyết

- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).

## Dữ liệu kiểm thử

- Không cần dữ liệu riêng.

## Các bước thực hiện

| # | Thao tác | Kết quả mong đợi | 📸 |
|---|---|---|---|
| 1 | Kiểm tra stack localhost và dọn dữ liệu | `Stack OK`; lệnh TRUNCATE thành công | 📸 |
| 2 | Khởi động lại api với khóa rỗng | api chạy lại; biến `ANTHROPIC_API_KEY` rỗng | 📸 |
| 3 | Tải lên và chờ Sẵn sàng | 202 rồi `ready: 3` | 📸 |
| 4 | Hỏi một câu | HTTP 503, `code: ai_unavailable` | 📸 |
| 5 | Gọi danh sách tài liệu | HTTP 200 | 📸 |
| 6 | Khôi phục api với `.env` | api chạy lại | 📸 |

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# OPS-008 — Thiếu ANTHROPIC_API_KEY: /ask 503, phần còn lại vẫn chạy
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs OPS-008 test_reports/OPS-008/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 2: Khởi động lại api với khóa rỗng"
ANTHROPIC_API_KEY= "${COMPOSE[@]}" up -d --force-recreate api; for i in $(seq 1 30); do curl -fsS "$API_URL/healthz" >/dev/null && break; sleep 2; done; "${COMPOSE[@]}" exec -T api sh -c 'echo "len(ANTHROPIC_API_KEY)=${#ANTHROPIC_API_KEY}"'

echo "### Bước 3: Tải lên và chờ Sẵn sàng"
seed_samples; wait_idle 300

echo "### Bước 4: Hỏi một câu"
ask 'Điều khoản tạm ứng là gì?'

echo "### Bước 5: Gọi danh sách tài liệu"
curl -sS -o /dev/null -w 'GET /documents %{http_code}\n' "$API_URL/api/v1/documents"

echo "### Bước 6: Khôi phục api với .env"
"${COMPOSE[@]}" up -d --force-recreate api; sleep 5; check_stack
```

## Tiêu chí đạt

Bước 3 và 5 thành công, bước 4 trả 503 `ai_unavailable`.

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.

## Dọn dẹp sau test
