Mọi chuỗi hiển thị lấy từ `vi.json`, không viết cứng trong `.tsx`.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/UI-002/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/UI-002`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/UI-002/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/UI-002/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/UI-002/logs/` và `./test_reports/UI-002/data/`.
6. **Tạo báo cáo** `./test_reports/UI-002/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/UI-002/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs UI-002 test_reports/UI-002/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# UI-002 — Không có chuỗi giao diện viết cứng trong TSX
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs UI-002 test_reports/UI-002/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Tìm ký tự tiếng Việt có dấu trong các tệp TSX (bỏ dòng chú thích)"
python3 - <<'PY'
import pathlib, re
VN = re.compile('[À-ỹ]')
hits = []
for f in sorted(pathlib.Path('frontend/src').rglob('*.tsx')):
    for n, line in enumerate(f.read_text(encoding='utf-8').splitlines(), 1):
        code = line.strip()
        if code.startswith(('//', '/*', '*')):
            continue
        if True and VN.search(code):
            hits.append(f'{f}:{n}: {code}')
        if False and re.search(r'>\s*[A-Za-zÀ-ỹ][^<>{}]{2,}<', code):
            hits.append(f'{f}:{n}: {code}')
print('\n'.join(hits) if hits else 'KHÔNG CÓ kết quả')
print('so_dong_nghi_van:', len(hits))
PY

echo "### Bước 2: Tìm văn bản JSX thuần chữ giữa > và <"
python3 - <<'PY'

VN = re.compile('[À-ỹ]')

print('\n'.join(hits) if hits else 'KHÔNG CÓ kết quả')
print('so_dong_nghi_van:', len(hits))
PY
```
