## Mục tiêu

Với 2 worker chạy song song, mỗi tài liệu chỉ được xử lý một lần.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/INT-009/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/INT-009`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/INT-009/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/INT-009/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/INT-009/logs/` và `./test_reports/INT-009/data/`.
6. **Tạo báo cáo** `./test_reports/INT-009/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/INT-009/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs INT-009 test_reports/INT-009/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Đã tạo virtualenv backend (`make venv`).
- Docker Desktop đang chạy (Testcontainers tự dựng PostgreSQL + pgvector cho test tích hợp).
- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).
- `docker compose ps worker` có 2 replica.

## Dữ liệu kiểm thử

- Không cần dữ liệu riêng.

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# INT-009 — Hai worker không lấy trùng một job
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs INT-009 test_reports/INT-009/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Chạy test tự động tests/integration/test_documents.py::test_two_workers_never_claim_the_same_job (Testcontainers)"
(cd backend && .venv/bin/pytest 'tests/integration/test_documents.py::test_two_workers_never_claim_the_same_job' -v)

echo "### Bước 2: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 3: Xác nhận có 2 worker"
"${COMPOSE[@]}" ps worker

echo "### Bước 4: Tạo và tải lên 10 PDF (tên khác nhau)"
for i in $(seq -w 1 10); do cp "$FIXTURES/sample/De_xuat_hop_tac_Minh_Phat.pdf" "$DATA_DIR/de_xuat_$i.pdf"; done; upload "$DATA_DIR"/de_xuat_*.pdf

echo "### Bước 5: Chờ xử lý và kiểm tra mỗi tài liệu chỉ có 1 job, 1 lần thử, chunk không trùng"
wait_idle 300; psql_q "SELECT d.filename, d.status, count(DISTINCT j.id) AS jobs, max(j.attempt) AS attempt, count(c.id) AS chunks, count(DISTINCT c.chunk_index) AS chunk_idx FROM documents d JOIN ingestion_jobs j ON j.document_id = d.id LEFT JOIN chunks c ON c.document_id = d.id GROUP BY 1,2 ORDER BY 1;"

echo "### Bước 6: Xem log 2 worker"
"${COMPOSE[@]}" logs --no-color --tail 60 worker
```

## Tiêu chí đạt

Mọi tài liệu `ready`, mỗi tài liệu đúng 1 job và `chunks = chunk_idx`.

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.
