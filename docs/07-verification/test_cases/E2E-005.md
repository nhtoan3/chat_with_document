## Mục tiêu

Người dùng hỏi một câu và nhận câu trả lời Markdown kèm nhãn cảnh báo AI.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/E2E-005/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/E2E-005`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/E2E-005/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/E2E-005/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/E2E-005/logs/` và `./test_reports/E2E-005/data/`.
6. **Tạo báo cáo** `./test_reports/E2E-005/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần UI: viết script Playwright `./test_reports/E2E-005/E2E-005.mjs` dùng `startEvidence('E2E-005')` từ `frontend/e2e/evidence.mjs` (`caption()` đầu mỗi bước, `shot()` tại mỗi 📸, `finish()` ở cuối) và chạy `node test_reports/E2E-005/E2E-005.mjs` từ gốc repo. Xem ví dụ ở README §4.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).
- Đã chạy `npm ci` trong `frontend/` (có Playwright 1.64.1).
- 3 PDF mẫu Sẵn sàng (`reset_data && seed_samples && wait_idle`).
- Ưu tiên chạy với Claude thật (Có `ANTHROPIC_API_KEY` trong `.env` ở gốc repo và đã khởi động lại api (`docker compose up -d api`).). Không có khóa → giả lập `/api/v1/ask` bằng `page.route` trả 200 `{"answer":"Tạm ứng **30%** giá trị đơn hàng…","latency_ms":8421}` và ghi rõ trong báo cáo.

## Các bước thực hiện

| # | Thao tác | Kết quả mong đợi | 📸 |
