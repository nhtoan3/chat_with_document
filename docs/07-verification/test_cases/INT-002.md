## Mục tiêu

Lô > 10 tệp bị từ chối toàn bộ bằng 422 `too_many_files`, không lưu tệp nào.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/INT-002/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/INT-002`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/INT-002/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/INT-002/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/INT-002/logs/` và `./test_reports/INT-002/data/`.
6. **Tạo báo cáo** `./test_reports/INT-002/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/INT-002/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs INT-002 test_reports/INT-002/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Đã tạo virtualenv backend (`make venv`).
- Docker Desktop đang chạy (Testcontainers tự dựng PostgreSQL + pgvector cho test tích hợp).
- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).

## Dữ liệu kiểm thử

- 11 bản sao của một PDF mẫu với tên khác nhau (script tự tạo trong `data/`).

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# INT-002 — Tải 11 tệp: từ chối cả lô
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs INT-002 test_reports/INT-002/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Chạy test tự động tests/integration/test_documents.py::test_too_many_files_rejects_whole_batch (Testcontainers)"
(cd backend && .venv/bin/pytest 'tests/integration/test_documents.py::test_too_many_files_rejects_whole_batch' -v)

echo "### Bước 2: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 3: Tạo 11 PDF hợp lệ có tên khác nhau"
for i in $(seq -w 1 11); do cp "$FIXTURES/sample/Hop_dong_khung_ABC_2026.pdf" "$DATA_DIR/tep_$i.pdf"; done; ls "$DATA_DIR"

echo "### Bước 4: Tải lên 11 tệp trong một request"
upload "$DATA_DIR"/tep_*.pdf

echo "### Bước 5: Kiểm tra không có tài liệu nào được lưu"
counts
```

## Tiêu chí đạt

Bước 4 trả 422 `too_many_files` và bước 5 có `total: 0`.

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.
