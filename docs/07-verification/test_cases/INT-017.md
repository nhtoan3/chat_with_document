## Mục tiêu

Khi không có tài liệu `ready` (rỗng hoặc chỉ có tài liệu đang xử lý / lỗi), `/ask` trả 409 `no_documents`.

## Nhiệm vụ của agent

1. Thực hiện test **chỉ trên localhost**: web `http://localhost:5173`, API `http://localhost:8000` (các dịch vụ phụ cũng ở localhost). Không gọi môi trường AWS.
2. Lưu **mọi** artifact của test case này trong thư mục riêng `./test_reports/INT-017/` (tính từ gốc repo). Chạy lại thì xóa thư mục cũ trước: `rm -rf test_reports/INT-017`.
3. **Quay video** toàn bộ quá trình thực hiện test → `./test_reports/INT-017/video.webm` (nhiều phiên thì `video-02.webm`, …).
4. **Chụp ảnh màn hình** làm bằng chứng tại mỗi bước có 📸 → `./test_reports/INT-017/screenshots/NN-<mô-tả>.png`.
5. Lưu output lệnh, log và dữ liệu sinh ra vào `./test_reports/INT-017/logs/` và `./test_reports/INT-017/data/`.
6. **Tạo báo cáo** `./test_reports/INT-017/report.md` theo [mẫu ở README §5](README.md#5-mẫu-báo-cáo-reportmd): kết quả từng bước, ảnh nhúng, liên kết video, kết luận ✅ Đạt / ❌ Không đạt / ⛔ Bị chặn.
7. Phần CLI: lưu script vào `./test_reports/INT-017/steps.sh` (mẫu bên dưới) rồi chạy `node frontend/e2e/run-cli.mjs INT-017 test_reports/INT-017/steps.sh` từ gốc repo — công cụ tự quay video, chụp ảnh khi kết thúc mỗi bước `### ` và lưu log.
8. Không sửa mã ứng dụng để test đạt. Bước nào lỗi thì ghi lại và tiếp tục các bước độc lập còn lại; luôn thực hiện phần dọn dẹp.

## Điều kiện tiên quyết

- Đã tạo virtualenv backend (`make venv`).
- Docker Desktop đang chạy (Testcontainers tự dựng PostgreSQL + pgvector cho test tích hợp).
- Stack local đang chạy (`make dev`), `check_stack` trong `frontend/e2e/lib.sh` báo OK (API `http://localhost:8000/healthz` và web `http://localhost:5173` phản hồi).

## Dữ liệu kiểm thử

- Không cần dữ liệu riêng.

## Các bước thực hiện

| # | Thao tác | Kết quả mong đợi | 📸 |
|---|---|---|---|
| 1 | Chạy test tự động `tests/integration/test_ask.py::test_no_ready_documents` (Testcontainers) | passed, exit code 0 | 📸 |
| 2 | Kiểm tra stack localhost và dọn dữ liệu | `Stack OK`; lệnh TRUNCATE thành công | 📸 |
| 3 | Hỏi khi bộ tài liệu rỗng | HTTP 409, `code: no_documents` | 📸 |
| 4 | Tải lên `corrupted.pdf`, chờ `failed`, hỏi lại | HTTP 409, `code: no_documents` | 📸 |
| 5 | Kiểm tra `qa_log` | Không có dòng nào (409 xảy ra trước khi gọi AI) hoặc ghi nhận nếu có | 📸 |

## Script gợi ý (`steps.sh`)

```bash
#!/usr/bin/env bash
# INT-017 — Không có tài liệu Sẵn sàng → 409 no_documents
# Chạy từ gốc repo: node frontend/e2e/run-cli.mjs INT-017 test_reports/INT-017/steps.sh
set -uo pipefail
source frontend/e2e/lib.sh

echo "### Bước 1: Chạy test tự động tests/integration/test_ask.py::test_no_ready_documents (Testcontainers)"
(cd backend && .venv/bin/pytest 'tests/integration/test_ask.py::test_no_ready_documents' -v)

echo "### Bước 2: Kiểm tra stack localhost và dọn dữ liệu"
check_stack || exit 1
reset_data

echo "### Bước 3: Hỏi khi bộ tài liệu rỗng"
ask 'Điều khoản tạm ứng là gì?'

echo "### Bước 4: Tải lên corrupted.pdf, chờ failed, hỏi lại"
upload "$FIXTURES/corrupted.pdf"; wait_idle 120; ask 'Điều khoản tạm ứng là gì?'

echo "### Bước 5: Kiểm tra qa_log"
psql_q "SELECT count(*) FROM qa_log;"
```

## Tiêu chí đạt

Bước 3 và 4 trả 409 `no_documents`.

Kết luận **⛔ Bị chặn** khi thiếu điều kiện tiên quyết (stack không chạy, thiếu khóa API, thiếu dữ liệu), không phải do lỗi của ứng dụng.
