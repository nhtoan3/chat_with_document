## Mục tiêu

Mỗi pull request được lint và test tự động; build image khi merge vào `main`.

## Phạm vi & đặc tả

`.github/workflows/ci.yml`:

| Job | Bước |
|---|---|
| `backend` | Python 3.12 → `ruff check` → `mypy app` → `pytest -m "not eval"` (Testcontainers) |
| `frontend` | Node 20 → `npm ci` → `eslint` → `tsc --noEmit` → `vitest run` |
| `build` (chỉ trên `main`) | Build image `api`, `web` (amd64), tag `sha-<short>`, push lên ECR |

Branch protection: bắt buộc `backend` và `frontend` xanh.

## Các bước thực hiện

1. Viết workflow.
2. Bật branch protection.
3. Mở một PR thử để xác nhận.
